# ADR

Ghi quyết định kiến trúc mới tại đây, 1 file 1 quyết định: `NNN-ten-ngan.md`
(`NNN` = số thứ tự 3 chữ số, tiếp theo ADR-004 ở `../ARCHITECTURE.md` mục 7 — ADR tiếp theo
là `005-ten-ngan.md`).

Mẫu:

```markdown
# ADR-005: Tên ngắn

- **Trạng thái:** Đề xuất / Đã áp dụng / Đã thay thế bởi ADR-xxx
- **Bối cảnh:** vì sao cần quyết định này
- **Quyết định:** chọn gì
- **Đã cân nhắc:** phương án khác, vì sao không chọn
- **Hệ quả:** được gì, đánh đổi gì
```

ADR nền tảng (001-004) nằm trực tiếp trong `../ARCHITECTURE.md` mục 7 vì đã định hình toàn bộ
kiến trúc ban đầu — không cần tách file riêng.
